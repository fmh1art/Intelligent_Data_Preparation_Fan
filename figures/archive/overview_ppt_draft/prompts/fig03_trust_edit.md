# 图3：面向手工PPT复绘的简化编辑 prompt

输入图：`exec-e6385c8e-c702-4e36-a22b-3136ef209664.png`。本编辑落实用户后续补充的用途：LLM图作为手工PPT复绘的构图参考。以下为实际编辑prompt。

Use case: scientific-educational.
请将输入图精简为之后能够用 PowerPoint 基础形状手工复绘的中文构图参考。保留白色背景、四个横向主模块、右上方交付模块、蓝青色细线与橙色反馈线。保持主流程左到右“说明目标”→“生成方案”→“工具处理”→“核对结果”，核对后向右上角“交付使用”。不要添加新模块，不使用真实人物照片。

目标是明显减少图形复杂度与文字量。所有模块标题保持现有准确中文，字体大且易读。各模块内部使用简洁扁平几何图标，不使用写实阴影或复杂人物细节。把四个主模块的复杂内容精简如下：
1. “说明目标”：两个人的简洁半身图标，中间是一张空白表单，下面一个小日历范围图标。删除“数据需求”“起始日期”“结束日期”及其他内部文字。
2. “生成方案”：简单电脑轮廓，屏幕内恰好三张小操作卡，只写“选数据”“定步骤”“定输出”。删除数字编号及全部说明句，不放真实代码。
3. “工具处理”：上下两张示意表，仅保留清晰网格和少量空白或短线单元格，上方表格表现参差格式，下方表格整齐。两表间一个小箭头和小齿轮。两张表的短标签仅为“处理前”“处理后”。删除所有日期、产品字母、数字、缺失补全值和具体字段名称，不能凭空编造数据。
4. “核对结果”：两张简洁空白表格，短标签仅为“来源”“结果”，配一个小放大镜和小天平。删除1250及所有总计数字，删除大型女性人物插画，不要把检查画成保证全部正确。
5. 右上“交付使用”保留简洁报告页与来源文件图标，删除所有说明句。由“核对结果”顶边连向此模块，箭头标签只写“通过”。

人机责任只需在“说明目标”和“核对结果”下方各放一个小型中性人形图标，不写长句。图标高度约40像素（以1536宽图计），不要压住模块边框或任何箭头。

准确重画反馈线：
- 较短橙色返回线必须从“核对结果”底边左部明确出发，先向下到较高的一条反馈通道，然后向左，最后向上用单一箭头进入“工具处理”底边；标签“发现错误，再修订”。以当前1536×1024布局为参考，可从x1100,y708下行到y790，左行到x758，再上行指入工具处理底边。
- 较长橙色返回线必须从“核对结果”底边右部明确出发，向下到更低的反馈通道，再向左，最后向上用单一箭头进入“说明目标”底边；标签“有疑问，先澄清”。可从x1260,y708下行到y855，左行到x55，再上行指入说明目标底边。
- 两条返回线都必须真正接触“核对结果”边框，不得悬空起始，不得从人形图标发出。两线不能交叉，也不能穿过任何图标或文字。核对模块下方的小人形图标可放在两条竖向反馈线之间、横向短反馈线之上。
底部只保留一句“保留来源与修改记录”。

请输出完整修订图。所有文字以本prompt明确列出的短标签为限，不自动补充介绍段落、数据、年份、数字、指标、公式、百分比、代码、保证正确的印章、公司标志或水印。
