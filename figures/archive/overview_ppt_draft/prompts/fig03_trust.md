# 图3：可靠数据准备中的人机协作
Use case: scientific-educational.
Asset type: original explanatory figure for a Chinese accessible research overview. Wide landscape PNG, highest native resolution preferably 3072x2048, white background.
Primary request: visualize a simple reliable data preparation process with a human clarifying goals and checking important decisions. Entirely original illustrated elements, not a copied architecture.
Composition: clear single horizontal chain with four generous modules. Exact labels from left to right: “说明目标”, “生成方案”, “工具处理”, “核对结果”. First module uses two neutral adults discussing a blank form and a date-range icon. Second uses an assistant computer with 3 short operation cards, no mascot or robot. Third uses a simple spreadsheet transforming untidy rows into organized rows, a small gear, no real code. Fourth uses a magnifier over source and result sheets and a scale icon conveying checking that totals agree.

A clearly separate warm orange return arrow along the bottom runs from the checking module back to “说明目标”, labeled “有疑问，先澄清”. A second short return arrow from checking to “工具处理” is labeled “发现错误，再修订”; place this return path above the bottom long path so lines do not cross. All arrows have unambiguous single heads and do not cross text.
Below the first and fourth modules, place modest human icons to show responsibility for defining goals and reviewing decisions. Bottom margin single brief phrase “保留来源与修改记录”. All text in Simplified Chinese. Do not say that checks guarantee all data is correct; no badges saying 100%, no performance scores.
Style: match the other two illustrations: white background, navy text, blue/teal modules, restrained orange used for feedback only, clean academic editorial illustration with rich but functional small objects. No large dark banners, glossy 3D, code blocks, formulas, tiny paragraphs, corporate logos or watermarks. All labels should remain readable at 166 mm print width, at least 32px when canvas is 1536px wide. No photorealistic portraits.
