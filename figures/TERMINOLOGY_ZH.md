# 术语规范与研究分支的中英文映射

## 两条研究主线

| 英文名称 | 统一中文名称 | 缩写 |
|---|---|---|
| AI for Data Prep | 基于人工智能的数据准备 | AI4DP |
| Data Prep for AI | 面向人工智能的数据准备 | DP4AI |

AI为总体研究范围，语言模型是本文的讨论重点；具身数据准备属于DP4AI向物理交互场景的扩展。正文不再用LM4DP和DP4LM指代这两个总方向。具体方法中的“语言模型”“大语言模型”和“多模态模型”仍按各自含义使用。

## 全文术语检查

| 术语 | 统一用法或概念边界 |
|---|---|
| 列语义类型识别 | Sato、Unicorn相关论述统一使用此称呼，明确识别的是列的语义类型。 |
| 表示 | 统一“表征/表示”的同义用法，按对象保留“语义表示”“梯度表示”“动作表示”等限定。 |
| 实体匹配、实体解析 | 记录是否描述同一对象的判定称为实体匹配；正文说明其为实体解析的关键步骤。参考文献题名及作者简介保留实体解析的原称。 |
| 模式匹配、问题与数据库模式的关联 | 前者判断跨来源字段的语义对应，后者将查询问题与数据库模式联系起来；不合并为同一任务。 |
| 错误修复、候选修复值 | 清洗任务统一称“错误修复”，Baran的候选输出称“候选修复值”；缺失数据的处理称“缺失值补全”。 |
| 指令数据选择 | 明确选择对象为用于训练的指令数据，替代语义不够明确的“指令选择”。 |
| 推理过程训练数据 | 指用于训练模型推理能力的解题步骤等数据，出现在OpenThoughts相关论述中。 |
| 推理上下文数据 | 指模型推理时使用的证据、示例等输入，与推理过程训练数据区分。 |
| 语义判断、执行反馈 | 疑难实例的含义判定称“语义判断”；智能体根据工具执行结果选择后续操作的语境使用“执行反馈”。 |
| 评测、评估、核验 | 按指标比较任务或系统称“评测”；数据价值判断称“评估”；依据约束或证据检查正确性称“核验”。普通叙述中的检查、检验、复核等动词按具体语义使用。 |
| 数据准备流程、评测基准 | 串联准备操作使用“数据准备流程”，衡量任务完成情况的基准使用“评测基准”。DiffPrep所涉及的“预处理配置”保留其具体范围。 |
| 评测数据污染、数据泄漏 | 前者强调训练接触了评测内容；后者强调训练或准备过程使用了不应获得的评测信息。训练集内部重复单独讨论。 |
| 检索增强生成（RAG） | 首次出现补充RAG，与图中RAG标签对应。 |
| 视觉语言动作模型（VLA） | 首次出现补充VLA，保留中文名称。 |
| 基础模型、预训练语言模型、大语言模型、多模态模型 | 按研究对象保留不同范围，不将它们当作可互换的简称。 |
| 微调、指令微调 | 指令微调属于具体微调形式；正文的微调讨论还涉及偏好标注，保留两者的范围差异。 |
